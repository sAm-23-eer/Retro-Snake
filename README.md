# Retro Snake 🐍

A classic Snake game built in C++ using the raylib library.

## Features

- Classic Snake gameplay
- Keyboard controls
- Food collection and scoring
- Collision detection
- Sound effects
- Retro-style graphics

## Tech Stack

- C++
- raylib

## Controls

| Key | Action |
|---|---|
| ↑ | Move Up |
| ↓ | Move Down |
| ← | Move Left |
| → | Move Right |

## How to Run

Make sure raylib is installed and configured, then compile:

```bash
g++ main.cpp -o snake.exe -lraylib -lopengl32 -lgdi32 -lwinmm
